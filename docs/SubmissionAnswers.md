**Challenge 1 — Intelligent Conversational AI for KSP Crime Database**

### Prototype Brief (1024-character limit — this draft is 885 characters)
> Setu is a bilingual (Kannada + English), voice-enabled conversational AI that lets Karnataka Police investigators query crime records in plain language instead of static dashboards or manual SCRB requests. It answers with visible source citations and a full audit trail, visualizes criminal networks, and proactively surfaces crime-pattern hotspots grounded strictly in case evidence (modus operandi, location, timing) — never demographic profiling. Built natively on Zoho Catalyst: a hybrid ZCQL + TF-IDF retrieval-and-synthesis approach powers the conversational core, Data Store's built-in OLAP powers hotspot analytics, and voice input is supported for English. It addresses SCRB's real bottleneck: 1,100+ stations generating data that's digitized but not analyzable in real time — turning a days-long manual query into a seconds-long, explainable answer an investigator can cite directly in a case file.
